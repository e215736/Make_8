■本ゲームについて
本ゲームは与えられた4つの数字を全て一回ずつだけ使い、演算子(+, -, ×, ÷)をそれぞれ1回以上用い、計算結果が8になるように組み合わせるパズルゲームです。


■起動方法
pythonの仮想環境をアクティブ化して、app.pyを実行すると起動できます。

※本ゲームではkivyというGUIフレームワークを利用しているため、起動にはkivyのインストールが必須となります。

●kivyのインストール方法
----------------------------------
% cd ソースが置かれているディレクトリ
% python3 -m venv venv
% source venv/bin/activate
% pip install --upgrade pip
% pip install kivy
----------------------------------

●kivyをインストール済み・インストール後のゲームの起動方法
----------------------------------
% cd ソースが置かれているディレクトリ
% source venv/bin/activate
% python app.py
----------------------------------


■基本操作
本ゲームでは設置されているボタンをマウスでクリックして操作します。
